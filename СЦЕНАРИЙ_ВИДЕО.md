# Сценарий видео для аттестации (не длиннее 5 минут)

Запишите видео с голосом: сначала демо (~2–2,5 минуты), потом разбор кода
(~2–2,5 минуты). Перед записью прорепетируйте один раз и заранее откройте
нужные файлы.

## Часть 1. Демо приложения (~2–2,5 минуты)

По порядку, как требует задание:

1. **Регистрация** test1@test.com (или вход, если уже есть аккаунт).
   Покажите ошибку входа: неверный пароль — текст виден на экране.
2. **Загрузка каталога** — индикатор, затем список; прокрутите список.
3. **Лайк** на карточке (анимация) и фильтр **«Избранное»** — покажите
   счётчик и пустое состояние «В избранном пока пусто», выключите фильтр.
4. **Добавление нового элемента**: кнопка «Добавить» → форма → название
   (попробуйте отправить пустое — валидация не пустит) → сохранение,
   элемент появился в списке.
5. **Экран деталей**: тап по карточке, Hero-анимация обложки, возврат
   назад. Лайк в деталях совпадает со списком.
6. **Состояние ошибки**: отключите интернет (шторка эмулятора — airplane
   mode), перезапустите приложение — текст ошибки и кнопка «Обновить».
   Включите интернет, нажмите «Обновить» — список вернулся.
7. **Выход** (Профиль → Выйти), **повторный вход** — избранное на месте.
8. **Дополнительные опции — назовите их вслух и покажите**:
   - Поиск: введите часть названия, список фильтруется на лету;
     введите абракадабру — заглушка «Ничего не нашлось».
   - Фильтры и сортировка: чип «Фантастика» + «Избранное» вместе,
     меню сортировки — «По названию», «Сначала новые», «По году».
   - Редактирование и удаление: откройте детали → карандаш → измените
     год → сохраните; корзина → диалог подтверждения → удалите.
   - Профиль: email, «В избранном: N», счётчик книг.
   - Тёмная тема: иконка в шапке (и переключатель в профиле) — все экраны
     читаются; тема сохраняется после перезапуска приложения.
   - Обновление в реальном времени: откройте Firebase Console →
     Firestore → измените название книги или добавьте документ —
     приложение покажет изменение сразу, без перезагрузки.
   - Анимации: Hero обложки при переходе в детали, «пружинка» лайка.

## Часть 2. Как устроен код (~2–2,5 минуты)

Откройте проект в IDE и пройдитесь по файлам (порядок ниже).

1. **`lib/main.dart` и `lib/app.dart`** — точка входа: инициализация
   Firebase, `MultiBlocProvider` с ThemeCubit и AuthCubit, MaterialApp
   со светлой и тёмной темой.
2. **`lib/logic/auth/auth_cubit.dart`** — состояния авторизации
   (unknown / authenticated / unauthenticated), подписка на
   `authStateChanges` — поэтому после перезапуска пользователь
   остаётся залогиненным.
3. **`lib/ui/screens/auth_gate.dart`** — переключает экран входа и
   каталог; после входа создаёт `CatalogBloc` через `BlocProvider`.
4. **`lib/logic/catalog/catalog_bloc.dart` (+ event, state)** —
   событие `CatalogStarted` подписывает bloc на два потока Firestore:
   книги и избранное пользователя. События: лайкнуть, переключить
   фильтр, поиск, добавить/изменить/удалить. Состояния: loading,
   loaded, error — поэтому у экрана каталога три состояния.
   Фильтры и сортировка хранятся в состоянии bloc, отфильтрованный
   список считается в геттере `visibleBooks`.
5. **`lib/data/repositories/catalog_repository.dart`** — вся работа
   с Firestore: `snapshots()` (обновление в реальном времени), лайк —
   документ `users/<uid>/favorites/<id книги>` (избранное у каждого
   аккаунта своё), add/update/delete. Виджеты к Firebase не обращаются.
6. **`lib/domain/entities/book.dart`** — модель: `fromFirestore`
   (id из `doc.id`), `toJson`, `copyWith`.
7. **`lib/ui/screens/catalog_screen.dart` и `lib/ui/widgets/book_card.dart`**
   — экран строится через `BlocBuilder`, карточка Stateless: данные
   вниз параметрами, события вверх колбэками. setState для данных
   каталога нигде не используется.
8. **`lib/ui/screens/book_details_screen.dart` и `book_form_screen.dart`**
   — детали, редактирование, удаление с диалогом подтверждения;
   форма с валидацией обязательного названия.
